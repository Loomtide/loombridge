# Loombridge 0.1.0

The evidence release. Everything in it traces to two live campaigns: the KidsAdventure
ratchet-door dogfood and the TideRunner door-one walk, whose 150+ finding ledger ships
in this repo as Docs/Design/TideRunnerDoorOneLedger.md.

## The headline: evidence is produced, observed, or honestly second-class

- The CLI now PRODUCES feel evidence itself: a capture recipe drives the seven canonical
  kinematic measurements through a declared harness seam (harness.feelSeam) and writes
  feel.json from op echoes, never from typed numbers. Sweep trials are retained raw;
  headline values are pure re-derivations; the coyote anchor reads the controller's own
  grounded field when declared.
- Playability is OBSERVED: a bridge-side recorder samples position, win state and clocks
  every frame while the agent drives; completionMethod derives from motion continuity
  against the contract's own kinematic bounds. A teleported win cannot say "played".
- Verdicts carry a sha per evidence file; the front door re-grades slices instead of
  trusting stored verdicts; required contract content no gate walks refuses by name;
  evidence binds to the run and editor session that made it. Agent-assembled evidence is
  labeled and capped, never silently equal to produced.

## The ratchet door (record once, replay deterministically)

- Pixel baselines gained human-consented tolerances, masks with structural drift
  discrimination, replay pacing, and capture-aligned settles (a pinned tick loop with
  the frame taken the instant the settle completes). Every anchor term change prints a
  consent line; a refused comparison re-anchors loudly instead of locking out.
- Focus-independent world taps: replays drive through an InputSystem session and no
  longer depend on editor focus.

## Delivery integrity

- The bundled bridge is bound to its sources by an embedded digest: a stale bundle
  refuses at install, update and doctor, and same-version-different-bytes drift between
  a project and the CLI turns doctor red naming the fix.

## Honesty fixes proven live

- Harness faults are never game defects, printed and exit-coded as such everywhere.
- The unmeasurable refuses instead of guessing: degenerate trajectories, unresolvable
  seams, absent provenance, unreadable manifests, unknown ui parameters.
- Introspection surfaces the previously write-only fields (enabled state, sorting) and
  collider bounds sync before every edit-mode read.

## Known limitations (tracked in the ledger)

- No op journal yet: a fabricated self-consistent observation buffer with forged
  producer markers is not detectable offline.
- editor.screenshot captures the editor view, not the game camera (documented; use
  runtime.capture_sequence view "game").
- The platformer pack's mock and contract can disagree about the player anchor; derive
  one from the other when authoring packs.
- Four pre-existing EditMode test failures (ComponentHandler x2, OpExecutor,
  TraceCollector) are unrelated to any feature and tracked.
